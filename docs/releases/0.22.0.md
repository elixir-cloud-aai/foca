FOCA 0.22.0 prepares apps for FOCA's ASGI release, which moves to Connexion 3 `AsyncApp` and removes Flask and Flask-Cors. Nothing is removed in 0.22.0: FOCA warns about what the ASGI release removes where it can, and adds replacements that already work on Connexion 2: request and claims accessors (`foca.context`), framework-neutral errors (`foca.errors`), a test client (`foca.testing`) and an ast-grep rule that finds Flask imports. The functions that take a Flask app (`get_app_config()`, `set_app_config()`, `enable_cors()` and `foca.factories.celery_app.create_celery_app()`) emit a `DeprecationWarning`, and FOCA logs each deprecation once per process; exception maps with raw Werkzeug classes are logged as deprecated and stop working with the ASGI release. Move your app now: see [Preparing for the ASGI release](https://foca.readthedocs.io/en/v0.22.0/preparing-for-asgi/) and the [migration guide](https://foca.readthedocs.io/en/v0.22.0/migration-0.22/). A `0.22.x` branch gets dependency and security fixes while apps migrate.
