foca-common 0.5.0 adds extra environment variables and rollouts on changed Secrets, autoscaling and topology spread constraints, and the settings of gateway apps, and follows FOCA 0.21.0's credentials from files.

## Features

- `extraEnv`, `extraEnvFrom` and `rolloutOnSecrets` (#626, #672)
- Autoscaling (HorizontalPodAutoscaler) and topology spread constraints (#627, #677)
- Gateway apps: `plugins`, `backendsKey` and `requireAccessControl`, and Flower (#628, #692)
- The check of variables that the chart sets also covers their `_FILE` forms, as FOCA refuses both at once (#625, #691)

## Documentation

- The chart's docs cover `server.request_id.trust_incoming` for apps behind a proxy (#695, #696)

## Maintenance

- A gateway example chart runs a real gateway plugin in the kind install test (#656, #658)
