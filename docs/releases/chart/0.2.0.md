foca-common 0.2.0 adds Gateway API routes, keeps the data of the bundled MongoDB and broker in persistent volumes, and no longer has defaults for a particular ingress controller. Apps that relied on the chart's ingress-nginx body-size annotation need to set it in their Ingress annotations; `mongodb.volumeSize` is deprecated in favour of `mongodb.persistence.size`.

## Breaking changes

- The Ingress no longer adds ingress-nginx's `proxy-body-size` annotation: controller annotations are set in `<valuesKey>.ingress.annotations`, and the docs give a body-size example per controller (#436, #440)

## Features

- Gateway API: an optional HTTPRoute (`<valuesKey>.httpRoute`) attached to an existing Gateway, with an optional redirect to HTTPS; Ingress, HTTPRoute and OpenShift Route are mutually exclusive, and the Route gets `<valuesKey>.route.annotations` (#397, #404)
- The bundled RabbitMQ keeps its queues in a PersistentVolumeClaim (`broker.persistence`) (#408, #411)
- The bundled MongoDB has the same persistence settings (`mongodb.persistence`), on by default; `mongodb.volumeSize` is a deprecated alias of `mongodb.persistence.size` (#419, #422)
- `helm uninstall` keeps the bundled MongoDB's volume by default (`persistence.resourcePolicy`) (#425, #427)

## Security

- Chart releases are attested (GitHub artifact attestation) and signed (Sigstore) (#403, #414)
