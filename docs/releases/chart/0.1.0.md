foca-common 0.1.0 is the first release of the Helm library chart for FOCA apps, published as `oci://ghcr.io/elixir-cloud-aai/charts/foca-common` from signed `chart-v*` tags, together with FOCA 0.16.0. App charts render their resources from its templates and keep only their own values.

## Features

- The library chart `foca-common`: the app's Deployment (non-root, read-only root file system, probes, optional Gunicorn settings), config overlay, Service, Ingress or OpenShift Route, NetworkPolicies and an optional MongoDB, with a thin petstore example chart, template tests and docs (#350, #357)
- An optional Celery worker and a bundled RabbitMQ broker (or an external broker), off by default (#351, #381)

## Fixes

- The bundled MongoDB's app user may also use the access-control database, and other findings of the pre-release review (#386, #389)
- The docs say to start Gunicorn without a control socket, as the root file system is read-only (#369, #370)
- The petstore chart serves the Swagger UI of an API at `/` (#368, #372)

## Documentation

- "ELIXIR On-Cloud" as the maintainer's name in the chart's metadata (#379, #380)

## Maintenance

- CI installs the petstore chart on a kind cluster, and chart tags release the chart to GHCR (#356, #365)
