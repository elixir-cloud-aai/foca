foca-common 0.3.0 runs apps with several replicas and a PodDisruptionBudget, and uses a keep-alive longer than the idle timeouts of common proxies. App charts need a template file for the budget.

## Features

- App replicas (`replicas`) and a PodDisruptionBudget (`podDisruptionBudget`); app charts need a template file for the budget (#584, #585)

## Fixes

- The petstore chart and the docs use a keep-alive of 100 s, longer than the idle timeouts of common proxies (#469, #478)

## Documentation

- The Gunicorn settings of the chart take precedence over FOCA's default settings in the image (#458, #463)
- The chart version in the docs is taken from `Chart.yaml` (#472, #481)

## Maintenance

- CI workflow and job names are aligned with the other repositories (#480, #482)
- Releases of the chart need approval, in the protected environment `release` (#449, #520; #563, #571)
- Dependency updates (#484, #555)
