foca-common 0.6.0 maps the size limit of the namespaces of FOCA 0.23.0's plugin store, and its limits of the files of WES runs.

## Features

- Gateway apps: `maxNamespaceSize` in the settings of the plugin store (`plugins.defaults.store` and per plugin), as `max_namespace_size` (#552, #774)
- Gateway apps: `maxCount` in the limits of the files of WES runs (`plugins.attachments`), as `max_count` (#781, #782)
