foca-common 0.6.0 maps the size limit of the namespaces of FOCA 0.23.0's plugin store, and its limits of the files of WES runs. The Ingress now fails to render if ingress-nginx's size limit of request bodies is below the app's.

## Breaking changes

- The Ingress fails to render if its annotation `nginx.ingress.kubernetes.io/proxy-body-size` is below the app's limit (`config.server.max_content_length`) or is not a size of ingress-nginx; the error names the value to set (or `0` for no limit). Without the annotation, nothing is checked; the chart still sets none (#785, #787)

## Features

- Gateway apps: `maxNamespaceSize` in the settings of the plugin store (`plugins.defaults.store` and per plugin), as `max_namespace_size` (#552, #774)
- Gateway apps: `maxCount` in the limits of the files of WES runs (`plugins.attachments`), as `max_count` (#781, #782)
