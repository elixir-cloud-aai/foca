foca-common 0.4.0 passes the key secret of the gateway plugins' store from an existing Secret, allows overrides of the app's probes, and accepts per-issuer audiences, as FOCA 0.20.0 does.

## Features

- The value `pluginStore.existingSecret` passes the plugin store's key secret from an existing Secret to the app and the worker, and rendering fails if the config overlay sets it (#565, #589; #644, #650)
- Overrides of the app's probes (`startupProbe`, `readinessProbe`, `livenessProbe`) (#603, #642)

## Fixes

- `requireAudience` accepts configurations in which each issuer has an `audience` of its own, as FOCA does (#604, #641)

## Maintenance

- Releases require a successful CI run of the release commit (#590, #591)
- Release preparation, together with FOCA 0.20.0 (#649, #654)
