## Contents

- [Getting started](getting-started.md): install FOCA, write a minimal app,
  the example apps and the Docker image.
- [Configuration](configuration/index.md): the configuration file, overlays
  and each of its sections.
- [Authentication](authentication.md): bearer token validation for trusted
  OpenID Connect providers.
- [Access control](access-control.md): policies, roles, resource ownership
  and the permissions API.
- [Deployment](deployment.md): running in production, Kubernetes and Helm,
  Docker Compose and verifying images and charts.
- [Helm library chart](helm-chart.md): the `foca-common` chart for the Helm
  charts of apps.
- [Utilities](utilities.md): helpers for common tasks.
- Migrating to [0.18.0](migration-0.18.md), [0.17.0](migration-0.17.md),
  [0.16.0](migration-0.16.md), [0.15.0](migration-0.15.md) and
  [0.14.0](migration-0.14.md): breaking changes and how to upgrade apps.
- [Contributing](contributing/index.md): how to contribute, the development setup,
  versioning and releases, and the Python guidelines.
- [API reference](reference.md): the code, generated from its docstrings.
- [Changelog](changelog.md): release notes.

The project adopts [semantic versioning](https://semver.org/); while the major
version is 0, minor releases may contain breaking changes, which are listed in
the [changelog](changelog.md) and the migration notes.
